버전 확정일: 2026-11-01

### 블랙 에이스·레드 조커 통합

- 타이틀의 PRESS START 화면에서 방향키 왼쪽 또는 오른쪽을 눌러 버전을 전환합니다. 버전별 로고·색상·노이즈·전용 자료와 게임 내 분기를 함께 전환하며, 마지막으로 선택한 버전을 기록합니다.
- 세이브를 버전별로 분리했습니다. 블랙 에이스와 레드 조커 각각 원작처럼 데이터 01/02 두 파일을 사용하므로 총 네 파일을 운용합니다.
- 원래 레드 조커 세이브를 통합판으로 옮기는 도구를 동봉했습니다. 자세한 절차와 제한은 아래 「세이브 사용과 이전」을 참고하세요.

### 세이브 브라더·배틀 메이트

- 다른 기기 없이 반대 버전의 세이브를 상대 삼아 브라더나 배틀 메이트를 등록하는 기능을 추가했습니다.
- 양쪽 버전에 통신 메뉴를 사용할 수 있는 일반 세이브를 만든 뒤, 로컬 통신에서 브라더 신청 또는 배틀 메이트 신청의 방을 만들고 혼자 기다립니다. 반대 버전에서 마지막으로 플레이한 데이터 01/02 중 한 파일이 상대가 됩니다. 같은 버전의 다른 파일은 선택되지 않습니다.
- 상대를 선택하면 대전 없이 등록 화면으로 이동합니다. 이름·버전·노이즈·링크 파워·카드·비밀 문구는 상대 세이브에서 가져옵니다. 같은 상대를 다시 등록하면 기존 칸을 갱신합니다.
- 등록 후 일반 저장을 해야 합니다. 반대쪽에도 등록하려면 버전을 바꾸어 같은 절차를 진행합니다. 가상 대전이나 대전 전적을 만드는 기능은 아닙니다.

### 자가 카드 교환

1. 첫 버전에서 로컬 카드 교환의 방을 만들고, 반대 버전 세이브를 상대로 카드를 제시합니다. 제시 정보를 기록한 뒤 취소 경로로 돌아오는 것이 현재 구현의 정상 흐름이며, 이때 카드 수는 변하지 않습니다.
2. 반대 버전으로 전환해 교환을 열고, 앞서 제시한 카드가 보이는지 확인합니다. 이쪽에서 줄 카드를 골라 확정하면 교환과 자동 저장을 진행합니다.
3. 처음 제시했던 버전의 해당 파일을 불러오면 교환 결과를 반영합니다. 여기서 일반 저장하면 양쪽 처리가 끝납니다. 양쪽 저장이 끝나기 전에는 다음 자가 교환을 진행하지 않습니다.

원작 규칙에 따른 스탠더드·메가 카드가 대상입니다. 기가와 애시드 일리걸·Ｍ오브크림슨은 제외됩니다. 받을 카드가 소지 한도에 도달했거나 제시한 카드를 이미 소모했다면 교환을 진행하지 않습니다. 저장 중단·반복 불러오기에서 중복 수령을 막는 기록을 추가했지만, 실제 기기에서의 저장 중단과 복구는 검증하지 않았습니다. 교환 도중 세이브를 외부에서 교체하거나 되돌리지 마세요.

### 부가 기능 메뉴와 어시스트

필드에서 START+SELECT를 함께 누르면 「부가 기능」이 열립니다. 긴 메뉴는 한 쪽 최대 세 줄로 나누어, 네 번째 선택지가 대사창에 가려지던 문제를 수정했습니다. 「다음 쪽」·「처음 쪽」으로 이동하며 B로 이전 메뉴에 돌아갑니다.

| 어시스트 | 설정과 동작 |
|---|---|
| 버스터 | B 버튼으로 쏘는 일반·차지·어빌리티 버스터 공격력 100~500%, 100% 단위. 위+Y 카운터는 제외 |
| 대미지 | 받는 HP 대미지 경감 0~100%, 20% 단위. 피격음·경직·상태 이상은 유지 |
| 제니 | 배틀 후 실제로 받는 제니 100~500%, 100% 단위. 결과 화면에는 원래 금액을 표시 |
| HP 회복 | 승리하거나 도주해 배틀이 끝나면 HP 완전 회복 |
| 도주 | 원래 도주를 시도할 수 있는 배틀의 도주 판정을 성공으로 처리 |
| 인카운터 | 하지 않음 / 저 / 중(원작) / 고 / 최고. 이벤트·고정 배틀을 없애는 기능은 아님 |

처음에는 원작 설정입니다. 어시스트 설정은 해당 게임 파일을 일반 저장하면 함께 남습니다. 통신 대전과 튜토리얼 전투는 어시스트 적용 대상에서 제외했습니다. 인카운터 「최고」의 즉시 조우 처리는 스텔스 보디 사용 중에는 원작 판정을 따릅니다.

### 배포 카드·대회 크라운·GX 카드

- 「받을 배포」에서 애시드 일리걸 또는 Ｍ오브크림슨을 고르면, 통신 메뉴의 게스트 목록에 선택한 배포를 가상으로 표시합니다. 이를 선택해 원작의 받기 화면으로 수령합니다. 선택한 배포는 임시 설정이므로 게임을 다시 시작하면 다시 골라야 합니다.
- 제1~3회 대회별 블루·실버·골드 크라운과 「증표 지우기」도 같은 방식으로 제공합니다.
- 배포 카드 수령 시 원작의 관련 기록을 함께 처리하여 클리어 후 퀸 버고Ω·잭 코르버스Ω의 출현 조건에 연결합니다. 선택만 한 상태와 실제 수령은 구분됩니다.
- 「카드・아이템」에서 GX 카드 세 장을 각각 한 번씩 직접 받을 수 있습니다. 인게임 표시 이름은 「페가수스 매직Ⅳ」「레오 킹덤Ⅳ」「드래곤 스카이Ⅳ」입니다. GX 카드는 네트워크의 가상 배포 목록에서 받는 방식이 아닙니다. 받은 뒤 일반 저장하세요.

### 암호 목록 메일·암호 보상 일괄 받기

- 게임 안에서 단서를 찾을 수 있는 암호 6개를 서프의 「암호 목록」 메일 한 통으로 안내합니다. 새 게임의 1장 안내 또는 기존 세이브에서 서프와 대화할 때 받으며, 같은 메일을 반복해서 보내지 않습니다. 메일을 보고 직접 암호를 입력하는 방식입니다.
- 나머지 외부 암호 46개의 보상은 「부가 기능 → 카드・아이템 → 다음 쪽 → 암호 보상 일괄 받기」에서 받을 수 있습니다. 배틀 카드 30개, 서브 카드 8개, 어빌리티 5개, W.E. 장비 3개의 암호에 해당합니다.
- 직접 입력했거나 이미 일괄 수령한 암호는 다시 지급하지 않습니다. 메일에 적힌 6개 암호는 일괄 수령에 포함하지 않습니다.
- 소지 한도 때문에 받지 못한 보상은 소지 수를 줄인 후 다시 받을 수 있습니다. 이미 가진 W.E. 장비는 추가 지급 없이 완료 처리하며, 새로 받은 보상 수와 구분해 표시합니다. 수령 기록은 일반 저장해야 남습니다.

### 히든 보스

- 클리어 후 ＦＭ 성의 「코스모 웨이브３」에서 애시드 에이스Ⅴ·그레이브 조커Ⅱ가 Σ 보스 방식의 무작위 배틀로 출현하도록 했습니다.
- 해당 보스를 쓰러뜨리면 원작의 은색 별 조건에 연결되며, 진행 상황은 일반 저장해야 합니다. 조우를 막는 인카운터 설정을 켰다면 해제해야 무작위 배틀을 만날 수 있습니다.

## 세이브 사용과 이전

- 통합판은 256 KiB(262,144바이트) raw 세이브 영역을 사용합니다. 블랙 에이스는 앞쪽, 레드 조커는 뒤쪽 128 KiB를 사용하며, 버전 선택·교환 기록 등을 추가합니다. 따라서 단순히 「세이브 형식 변경 없음」인 패치가 아닙니다.
- 기존 블랙 에이스의 게임 데이터 위치는 유지합니다. 원본 세이브는 백업한 뒤 사본을 사용하고, 사용 환경에서 ROM 파일명에 맞춰 일반 세이브를 연결하세요. 현재 버전으로의 실제 세이브 이전은 아직 검증하지 않았습니다.
- 이전 빌드의 저장 스테이트에는 예전 코드·그림·메모리가 남아 있을 수 있습니다. 새 ROM을 처음부터 열어 일반 세이브로 이어 하세요.
- 레드 조커 원본 세이브를 가져오려면 동봉한 도구로 새 파일을 만듭니다.

  ```text
  python merge_version_saves.py --black-ace "BA-original.sav" --red-joker "RJ-original.sav" --output "Ryuusei3-KO-v1.0.sav"
  ```

- 레드 조커만 옮길 때는 `--black-ace "BA-original.sav"`를 생략합니다. 블랙 에이스 영역은 비우고 레드 조커 선택으로 시작하도록 만듭니다.
- 이전 도구는 128/256 KiB raw .sav와 버전 표식을 확인하며, 뒤쪽 영역이 사용 중인 기존 통합 세이브, .dsv 컨테이너, 저장 스테이트는 받지 않습니다. 원본이나 이미 있는 출력 파일을 덮어쓰지 않습니다. 손상된 세이브를 수리하거나 내부 데이터의 정상 여부를 보증하는 도구는 아닙니다.
